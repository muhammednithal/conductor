# Milestone 4 — Live Run Viewer in the Web Dashboard

## Goal
Build the React web dashboard with a live run viewer that shows real-time step state updates via SSE, a run history list, and run detail views.

## Scope
- React + TypeScript web app scaffolded with Vite
- Authentication flow: login page, JWT stored in memory (not localStorage)
- Run history list: paginated list of workflow runs with status badges
- Run detail view: step-by-step execution status with live updates via `GET /runs/{id}/stream` SSE
- SSE fan-out in api-ai: subscribe to Redis pub/sub `conductor:events:{run_id}` and forward to SSE clients
- Worker status page: table showing hostname, status, last heartbeat, capacity

## Non-Goals
- Drag-and-drop workflow builder (M5)
- Cost/latency dashboard charts (M6)
- RAG support

## Acceptance Criteria
1. Step state changes appear in the run viewer within 2 seconds of the state change in Postgres
2. The run history list shows all runs for the authenticated user, sorted by `started_at` descending
3. The worker status page reflects the current live worker pool
4. The SSE connection automatically reconnects if the stream is interrupted
5. TypeScript `make test` and `make lint` pass in `/web`
