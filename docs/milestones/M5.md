# Milestone 5 — Visual Workflow Builder and RAG Support

## Goal
Add a drag-and-drop DAG builder to the web dashboard and implement the `rag` query step type in the api-ai service, enabling end-to-end RAG example workflows.

## Scope
- Drag-and-drop workflow builder in React: nodes represent steps, edges represent `depends_on` dependencies, exports as `dag_definition` JSON
- `rag` step type: `POST /ai/rag/query` with SSE streaming response `{chunk, done}`
- End-to-end RAG example workflow: chunk → embed → rag query
- Save workflow DAG via `POST /workflows` from builder export
- Vector store integration for embedding retrieval (configurable via env var)

## Non-Goals
- Custom step type plugins
- Multi-tenant vector stores
- Observability dashboards (M6)

## Acceptance Criteria
1. A workflow created in the drag-and-drop builder can be saved and triggered; it executes end-to-end
2. The `rag` step type returns a streaming SSE response with `{chunk, done}` frames; the run viewer displays chunks as they arrive
3. An end-to-end RAG workflow (embed → store → rag query) completes with `SUCCEEDED` status on all steps
4. The workflow builder validates that the DAG has no cycles before allowing save
5. `make test` and `make lint` pass in `/web` and `/api-ai`
